# F25-AI-Lab

Course-lab solutions for CAI601400 Artificial Intelligence, organized by lab. Each folder contains Python source, captured run output (`output.txt`) and a written `.docx` report. Python 3.10+; no third-party runtime packages are required.

## Run
```bash
python3 Lab-1/lab1_compare.py
python3 Lab-1/lab1_rules.py
python3 Lab-2/lab2_percepts.py
python3 Lab-2/lab2_model.py
python3 Lab-3/lab3_search.py
python3 Lab-4/lab4_astar_audit.py
```

All scholarship scores/probabilities and thresholds are synthetic demonstrations; no model is trained and no real applicant is assessed. Classroom outputs are simulated labels and do not control equipment. Search examples use the graph, weights, and tie-breaking documented in each report.

## Contents
- `Lab-1/`: rule/probability comparison and transparent rule tests; `Lab1_Report.docx`
- `Lab-2/`: classroom reflex/stateful agent and trace; `Lab2_Report.docx`
- `Lab-3/`: BFS, DFS, DLS, IDDFS and UCS; `Lab3_Report.docx`
- `Lab-4/`: A*, UCS, heuristic audit and overestimate experiment; `Lab4_Report.docx`

See report references for sources. Outputs are reproducible with the commands above.
